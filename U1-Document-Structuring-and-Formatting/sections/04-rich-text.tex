\section{Rich text formatting}
	In document design, \emph{rich text formatting} refers to the enhancement of plain text through typographical variations, such as changes in font weight, posture, family, size, or color, so as to establish visual hierarchy, emphasize key terms, or distinguish specific content elements. Rich text formatting in \LaTeX\ is achieved by enclosing target text within dedicated styling commands or using semantic markup directly inside the plain-text source file.
